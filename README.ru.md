# Ship Invaders

**Русский** | [English](README.en.md)

Прототип аркадного шутера на Python и Pygame с кораблём игрока, волнами врагов, снарядами, звуком и графическими ресурсами.

## Что находится в репозитории

- Точка входа игры — `shipinvaders/main.py`.
- Изображения и звуки находятся в `shipinvaders/images/` и `shipinvaders/sounds/`.

## Запуск и настройка

Установите Pygame (`pip install pygame`) и запустите `python shipinvaders/main.py` из корня репозитория.

## Примечания

В репозитории есть файл настроек PyInstaller. Собирайте исполняемый файл после проверки запуска игры в своей среде.
