# Ship Invaders

[Русский](README.ru.md) | **English**

A Python/Pygame arcade shooter prototype with a player ship, enemy waves, projectiles, sound, and image assets.

## Included in this repository

- The game entry point is `shipinvaders/main.py`.
- Images and sounds are stored in `shipinvaders/images/` and `shipinvaders/sounds/`.

## Getting started

Install Pygame (`pip install pygame`) and run `python shipinvaders/main.py` from the repository root.

## Notes

The repository includes a PyInstaller spec file. Build packaging only after confirming the game runs in your environment.
